# 名前・状態・回数・テキスト

| タグ | コンポーネント | 表示するもの |
| --- | --- | --- |
| `livesplit-game` | [Game](game.md) | ゲーム名・カテゴリ |
| `livesplit-text` | [Text](text.md) | 固定文字列、走行情報、Custom Variableを左右または2行で表示 |
| `livesplit-status` | [Status](status.md) | 接続中・接続済み・再接続待ちや設定エラー |
| `livesplit-value` | [Value](value.md) | fieldで選んだ単独項目をラベルなしで表示 |
| `livesplit-hotkey-indicator` | [Hotkey Indicator](hotkey-indicator.md) | 現状は未知色の線と「取得不可」。Bridge v4の制限あり |
| `livesplit-current-split` | [Current Split](current-split.md) | 現在区間の名前 |
| `livesplit-previous-split-name` | [Previous Split Name](previous-split-name.md) | 直前区間の名前 |
| `livesplit-split-progress` | [Split Progress](split-progress.md) | 終了した区間数と全区間数 |
| `livesplit-attempts` | [Attempts](attempts.md) | 挑戦回数 |
| `livesplit-completed-attempts` | [Completed Attempts](completed-attempts.md) | 完走回数 |
| `livesplit-phase` | [Phase](phase.md) | 待機中・計測中・一時停止・完走 |
| `livesplit-comparison` | [Comparison](comparison.md) | 選択中の比較対象名 |
| `livesplit-timing-method` | [Timing Method](timing-method.md) | 選択中の計測方法名（Real Time / Game Time） |
