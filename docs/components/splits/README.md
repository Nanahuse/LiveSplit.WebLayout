# Splits

区間ごとの時間・差分・比較値を表で表示する `<livesplit-splits>` です。

- [列の種類・比較対象](columns.md)
- [表示行数・精度・既定値](settings.md)
- [枠・列幅・余白・CSS](style.md)
- [Subsplits](subsplits.md)

```html
<livesplit-splits></livesplit-splits>
```

既定は累積差分と累積時間の2列です。未到達のBest Segmentを常時表示したい場合は`Comparison Segment Time`列を使います。未到達時に比較区間時間、到達後に区間差分を表示したい場合は`Segment Delta or Segment Time`を使います。
